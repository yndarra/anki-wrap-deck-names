## Wrap Long Deck Names

Settings open in a window (Tools → Add-ons → Config). `name_width`: width of the deck name column (`20em`, `300px`, `30vw`, …). `table_scale`: width of the whole deck list table in % (100 = as is, 120 = 20% wider; the extra space goes to the name column).

Настройки открываются в окне (Инструменты → Дополнения → Config): ширина столбца названий и ширина всей таблицы в процентах.
